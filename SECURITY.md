# Security policy

This repository is a **research and teaching analysis**. It is not a trading system, executes no trades, holds no
funds and needs no secrets. The case file is fictional; nothing here is investment advice.

## Reporting

- **Scientific errors** (a wrong number, a misapplied theorem, a claim that overstates its source): open an issue
  with the `claim-audit` template. These are welcome and treated as first-class findings.
- **Software vulnerabilities** (for example in the static site or the build scripts): please use GitHub's private
  vulnerability reporting ("Report a vulnerability" on the Security tab) rather than a public issue.

## Supported versions

Only the latest commit on `main` is supported.
