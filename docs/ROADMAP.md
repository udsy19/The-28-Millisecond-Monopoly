# Roadmap and acceptance gates

This document is a dependency-aware execution plan, not a claim that all research is complete. The status of an implementation can be determined by code/tests and GitHub issues rather than prose.

## P0: Lock the project thesis and source boundaries
- [x] Canonical fictional case and separate assumptions in data/.
- [x] Establish initial investment hypothesis and reversal conditions.
- [x] Formalize evidence classes and prevent fake certainty.
- [x] Record verifiable high-quality source links.
- [ ] Independent research reviewer checks each source against supported claim and date.

**Exit:** facts, assumptions and claims cannot be confused.

## P1: Exact mathematical baseline
- [x] Enumerate all 16 classical local CHSH deterministic strategies.
- [x] Verify 75% optimum, quantum Tsirelson ceiling, and perfect one-bit classical strategy.
- [x] Bound event-conditioned 820/1,000 p-value under complete fair trials.
- [ ] Extend to best quantum response against arbitrary nonuniform setting distributions.
- [ ] Independent Bell/causality expert review.

**Exit:** alternative comparisons are mathematically correct and have tests.

## P2: Physical and adversarial feasibility
- [x] New York–London geodesic, vacuum light cone and assumed fibre timing.
- [x] Direct unrepeated fibre link-budget sensitivity with explicit rate ambiguity.
- [x] Classical local detection-postselection construction and seeded Monte Carlo.
- [ ] Model loss and false detections using all issued trials in an event-ready variant.
- [ ] Evaluate quantum memory inventory/recharge and link architecture options.
- [ ] Validate finite-sample inference under test protocol variations.
- [ ] Examine special operational scheduling/settlement edge cases.

**Exit:** the causal × optical frontier has identified uncertainties, not merely a chart with arbitrary assumptions.

## P3: Commercial test and reverse underwriting
- [x] Optimize classical alternative, not merely the startup's 74% demonstration.
- [x] Recover $13.921 marginal game payoff and implied 3.59M annual rounds.
- [x] Fixed-quantum strategy stress test for nonuniform setting odds.
- [ ] Model market slippage, actual latency, application costs, opportunity classes and payoff asymmetry.
- [ ] Bound commercial break-even volumes under source-rate restrictions.
- [ ] Make a reusable pricing/pilot term sheet **without inventing a customer commitment**.
- [ ] Research alternative certified randomness/network-verification pivot.

**Exit:** investment conclusion has sensitivities, competitor benchmark and concrete counterevidence gates.

## P4: Creative exhibition and scientific communication
- [x] Implement an offline web 'investment war room' with causal, audit, and financial sliders.
- [x] Generate SVG frontier, optical-loss, and payoff-surgery figures.
- [x] Generate an initial executive memo from the same functions as the figures.
- [x] Build a reproducible Jupyter investigation.
- [ ] Cross-check site computations against Python reference fixtures.
- [ ] Accessibility / screen-reader / mobile UX audit.
- [ ] Build a one-page investor brief and a 3-minute oral defense.
- [ ] Add a deliberately skeptical 'founder rebuttal' and response appendix.

**Exit:** beautiful interface that still explains how numbers were obtained.

## P5: Autonomous implementation and scientific review
- [x] Agent-specific prompts and file ownership.
- [x] Machine-readable task DAG; build and required-artifact gates.
- [ ] Validate actual local agent CLI orchestration and PR publication behavior on a clean clone.
- [ ] Automated and independent red-team review against evidence policy.
- [ ] CI green on main; no failing or skipped experiments.
- [ ] Human scientific/commercial final signoff before public claims are treated as established.

**Exit:** another student or reviewer can reproduce, audit and understand all claims from a clean clone.

## P6: Course submission
- [x] Phase 1 hypothesis draft.
- [x] Phase 2 tested computational code and figure/table pipeline.
- [x] Phase 3 generated executive memo draft.
- [ ] Export chosen submission files and check exact course submission constraints.
- [ ] Confirm all sources, limitations and individual-work/AI-use disclosures.
- [ ] Ensure output can run in a clean environment without API access.

**Final command:** make check. This gate does not replace qualitative source verification or independent investment reasoning.
