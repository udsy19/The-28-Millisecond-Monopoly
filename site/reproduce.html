Reproduce / Documentation

Re-run every number from a clean checkout.

The notebook runs from a fixed seed () with Monte Carlo rounds per check, and re-running it produces a byte-identical results/results.json. Nothing in the writing or on this site is typed by hand.

Commands

Requirements: Python 3.13; Node 22 for the parity tests, PDFs and screenshots; pandoc for PDFs (no LaTeX).

git clone https://github.com/udsy19/The-28-Millisecond-Monopoly
cd The-28-Millisecond-Monopoly
python3.13 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m pytest -q
scripts/package.sh

scripts/package.sh re-executes the notebook from a clean kernel, rewrites results/results.json, renders every deliverable from it, checks that every number in the writing is traceable (scripts/check_numbers.py), prints the PDFs into reports/ and builds submission.zip.

Build this site

The site is plain HTML, CSS and JavaScript in site/, with no framework and no build step. scripts/build_site.py only assembles the deployable folder: it copies site/, puts results/results.json at data/results.json, copies figures/*.png and reports/*.pdf (warning about any PDF that has not been built), and adds .nojekyll.

python scripts/build_site.py --out _site && python -m http.server -d _site 8000

Open http://localhost:8000/. Opening the HTML files directly from disk will not work: the pages fetch data/results.json, and they say so instead of showing blanks. GitHub Pages runs the same script from .github/workflows/pages.yml.

How numbers flow

  1. src/chsh.pyPure functions, deterministic given their inputs; Monte Carlo takes an explicit seeded generator.
  2. analysis.ipynbRuns experiments E1–E6 from seed and writes every value and its display string.
  3. results/results.jsonThe single source of truth: values for code, display for writing.
  4. deliverables/templates/*.mdEach double-brace placeholder is filled by scripts/render_deliverables.py; an unknown key is an error.
  5. scripts/check_numbers.pyFails CI on any number in the writing it cannot trace to display.
  6. site/ + data/results.jsonEvery page marks numbers as <span data-r="key">; common.js fills them at load. Interactive values are computed by model.js.

Cite and contribute

Cite with CITATION.cff, and please also cite Ding & Jiang (arXiv:2407.21723) and the other sources on the evidence page.

The Photon That Didn't Show Up: photon loss and the CHSH trading edge.
https://github.com/udsy19/The-28-Millisecond-Monopoly

Contributions follow CONTRIBUTING.md:

  • Every number comes from code; never type a result into a template or a page.
  • Never weaken a test to make it pass; re-derive, decide which side is wrong, and log it in DECISIONS.md.
  • Change src/chsh.py and site/model.js together; the parity test holds them to 1e-12.
  • Negative results and limitations stay.
